# BIT 2118 — Scientific Computing

**Institution:** Mount Kenya University (MKU)

## Task 05: Matrix Algebra and Matrix Operations

This project demonstrates matrix algebra and matrix operations using Python and NumPy. It explores matrix multiplication, rotation, scaling, combined transformations, determinants, and coordinate transformations.

## Programs

- `code/Task_05_matrix_algebra.py` — Demonstrates matrix operations by rotating a square through 45 degrees, applying horizontal and vertical scaling, combining transformation matrices, and calculating the determinant.
- `code/Task_05_matrix_algebra_modified.py` — Uses a modified rotation angle of 30 degrees and different scaling factors to investigate how changing matrix values affects the final coordinates and transformation results.
