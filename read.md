# BIT 2118 — Scientific Computing

**Institution:** Mount Kenya University (MKU)

## Task 04: Floating-Point Arithmetic and Numerical Errors

This project demonstrates floating-point arithmetic and numerical errors using Python and NumPy. It explores how computers represent decimal numbers, calculate approximation errors, and maintain numerical accuracy when performing mathematical operations.

## Programs

- `code/Task_04_numerical_errors.py` — Demonstrates floating-point comparisons, absolute error, relative error, and numerical stability using the original test values.
- `code/Task_04_numerical_errors_modified.py` — Uses modified mathematical values and different test cases to investigate how changing inputs affects numerical errors and calculation accuracy.
